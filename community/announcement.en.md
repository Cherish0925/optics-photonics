# An open software catalogue for optics and photonics

We have published a bilingual catalogue of **96 tools and product families across 14 optical and photonic task domains**:

https://github.com/Cherish0925/optics-photonics

The catalogue separates commercial software, free and open-source tools, and restricted free offerings. Each entry connects the physical method and use case to licensing, programming interfaces, compute requirements, limitations and primary sources. API access, official or community MCP integrations, and agent Skills are recorded separately.

English and Chinese editions are downloadable, self-contained HTML files with search, filters, comparison and CSV / JSON export. A searchable index brings together 200 documentation, website, repository, license and integration links. Stable identifiers, JSON data and schema, Markdown and `llms.txt` support reuse by people and agents.

Corrections, missing tools and reproducible interface examples are welcome. Original code and catalogue descriptions are MIT-licensed; referenced projects retain their own licenses.
