# 开源：光学与光子学软件目录

我们发布了一个面向科研、工程与 AI Agent 的双语软件目录，收录 **96 项工具与产品族，覆盖 14 个任务领域**：

https://github.com/Cherish0925/optics-photonics

目录将商业付费、免费开源、免费但授权受限的工具分开，逐项整理物理方法、适用任务、许可证、编程接口、计算环境、应用依据、局限与一手来源。原生 API、官方或社区 MCP、Agent Skills 分别标注，避免把文档查询入口误认为求解器执行接口。

中英文各有完整、可下载的独立 HTML，支持离线搜索、筛选、对比和 CSV / JSON 导出。资料索引汇集 200 个文档、网站、代码、许可证及集成链接；稳定编号、JSON 数据与 Schema、Markdown、llms.txt 便于后续集成。

欢迎补充遗漏、纠正来源与许可证、提交可复现的接口示例。原创代码与目录说明采用 MIT 许可证，所引用软件与资料保留各自授权。
