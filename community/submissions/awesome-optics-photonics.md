# Add an open bilingual software resource guide

I maintain [Optics · Photonics](https://github.com/Cherish0925/optics-photonics), and propose a short software-resource-guide section for this community list.

The catalogue maps 96 optical and photonic tools and product families across 14 task domains. It may help readers of your open-source tooling list compare physical methods, license boundaries, programming interfaces and compute requirements, with original documentation or repositories linked for each entry. It includes an open-source filter, while separately identifying commercial and restricted-free options.

It provides complete English/Chinese HTML editions, a searchable 200-link resource index, reusable JSON and Markdown, and source-based API/MCP/Skills classifications.

- Browse: https://cherish0925.github.io/optics-photonics/
- Original code and catalogue descriptions: MIT

The proposal adds one guide without changing existing research or tool entries. Thank you for maintaining this resource.
