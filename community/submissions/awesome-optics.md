# Resource suggestion: bilingual optics software catalogue with licensing and API references

I maintain [Optics · Photonics](https://github.com/Cherish0925/optics-photonics), an MIT-licensed English/Chinese software catalogue, and would like to suggest it as a related resource for this list.

It covers 96 tools and product families, including Meep, MPB, RayOptics, prysm, POPPY and HCIPy. Each entry connects physical methods and use cases to licensing, programming interfaces, compute requirements and primary sources. Commercial, open-source and restricted-free options are separated.

The [browsable edition](https://cherish0925.github.io/optics-photonics/) is downloadable as self-contained HTML. JSON and Markdown support reuse. API access is distinguished from official/community/unverified MCP and Skills.

A possible entry:

> [Optics · Photonics](https://github.com/Cherish0925/optics-photonics) — Bilingual optics software catalogue with physical models, licensing, programming interfaces and primary-source references; offline HTML and reusable JSON.

Would a resource of this type fit the list? Thank you for maintaining it.
