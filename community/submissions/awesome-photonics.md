# Add bilingual optics software catalogue to other links

This adds a software-selection resource under `other links`. I maintain the linked catalogue.

Your list gives photonics users a useful route into layout, simulation and analysis tools. The catalogue adds structured comparisons of physical methods, licensing, native programming interfaces, compute requirements and primary sources across 96 tools and product families. It includes many projects already listed here, such as gdsfactory, KLayout, SAX, Meep and Tidy3D.

The English and Chinese editions work as downloadable standalone HTML files. JSON and Markdown support reuse by research workflows and agents. Commercial, open-source and restricted-free tools are separated, and native APIs are distinguished from official/community/unverified MCP and Skills.

- Browse: https://cherish0925.github.io/optics-photonics/
