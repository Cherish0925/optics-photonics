02 / OPTICS & PHOTONICS

Use the scientific environment you need.

The connector runs on Windows, macOS and Linux with Python 3.10+. Each solver keeps its own platform and license requirements.

python -m pip install "git+https://github.com/Cherish0925/optics-photonics.git@optics-v0.2.0"
optics-photonics info tmm
optics-photonics prepare tmm

Save these inputs as inputs.json. The calculation returns a compact result and a spectrum CSV.

{
  "n": [
    1,
    1.45,
    1.52
  ],
  "thickness_nm": [
    100
  ],
  "wavelength_nm": [
    450,
    550,
    650
  ],
  "polarization": "s",
  "angle_deg": 0
}
optics-photonics run tmm spectrum --inputs "@inputs.json"

Reuse an installed environment

optics-photonics bind tmm --python /path/to/python --threads 1 --concurrency 4
optics-photonics environments

Use a release wheel when Git is unavailable. Prepare creates an isolated environment only for listed recipes; commercial tools, MPI builds and GPU distributions use their own installers. Configuration is kept under OPTICS_HOME or ~/.optics-photonics.

Install once, keep environments

New connector versions produce a new plugin directory. The host updates its installed package; software environments and saved experiments remain separate.

Local and remote execution

Run MCP on the computer with the scientific environment. A remote host can launch it over SSH; calculations and large files remain on the computing machine.

Each generated package includes INSTALL.md with the host command, Python location and update procedure. The same MCP server serves all host packages.

06 / OPTICS & PHOTONICS

Keep research calculations running.

Submit a complete program or a dependency graph. Independent workers continue after the Agent disconnects; reconnect using the same research run ID.

optics-photonics submit tmm --program research.py --inputs "@inputs.json" --request-id study-001
optics-photonics status RUN_ID
optics-photonics files RUN_ID
optics-photonics read RUN_ID calculate/attempt-1/result.json
optics-photonics download RUN_ID calculate/attempt-1/spectrum.csv spectrum.csv

Native program

INPUTS supplies JSON parameters. OUTPUT_DIR stores arrays and models. RESULT returns compact JSON.

Parallel and sequential

Independent steps can run concurrently. Dependencies set order; bindings transfer selected outputs into the next inputs. Keep a persistent solver session in one program.

Resources

A shared CPU budget coordinates all submitted runs. Each environment declares its thread count and process concurrency. MPI, GPUs, licenses and clusters use the solver’s launch configuration.

Scientific records

Inputs, source, software versions, environment settings, results and native data files stay together. Written files can be read while other calculations continue.

Resume preserves completed steps and reruns unfinished steps in a new attempt directory. Append new steps to the same run. Native solver checkpoints and remote task IDs remain part of the research program.
