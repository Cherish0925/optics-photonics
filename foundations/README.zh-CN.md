# 基础框架：场 · 物质 · 相互作用

[English](README.md) · [English HTML](../docs/foundations.html) · [中文 HTML](../docs/foundations.zh.html)

## 最简洁的统一模型

对于光学与光子学，一个足够准确、清晰且能够跨尺度使用的总框架是：

\[
\boxed{\text{光学 / 光子学} = \text{场} + \text{物质} + \text{相互作用}}
\]

这不是用一句口号取代 Maxwell 理论、量子电动力学、固体物理、统计物理或器件工程，而是一个统一的组织框架。它的价值在于：从几何光学到量子光学，从显微尺度到天文尺度，从基础理论到工程器件，同一套三元结构始终成立。

更明确地写，可以把一个光学系统表示为

\[
H = H_{\mathrm{field}} + H_{\mathrm{matter}} + H_{\mathrm{int}}
    + H_{\mathrm{drive}} + H_{\mathrm{env}}.
\]

在经典连续介质语言中，对应于

\[
\text{Maxwell 场动力学}
+
\text{物质本构响应}
+
\text{源、边界与耗散}.
\]

自由空间传播属于场自身的动力学。光源、样品、透镜、波导、调制器、增益介质和探测器都属于物质系统，并通过耦合改变场或被场改变。几何主要通过物质的空间分布、界面、边界条件和背景空间进入问题。

## 1. 场

“场”是光本身的物理自由度。

在经典层面，它是电磁场，例如

\[
\mathbf E(\mathbf r,t),\quad
\mathbf B(\mathbf r,t),\quad
\mathbf D(\mathbf r,t),\quad
\mathbf H(\mathbf r,t).
\]

在量子层面，它仍然是电磁场，只是被量子化了。电场与磁场变成算符，正常模可以用产生与湮灭算符表示：

\[
\hat a_k,\qquad \hat a_k^\dagger.
\]

因此，光子不是“电磁场之外的另一种东西”。光子是量子化电磁场的激发。量子光学当然仍然有电磁场；变化的是描述它所用的状态空间、算符和测量理论。

光的各种自由度和信息载体都属于场的状态结构，例如：

- 频率与波长；
- 波矢与动量；
- 相位；
- 偏振与 helicity；
- 振幅与强度；
- 空间模式与波前；
- 时间模式与脉冲形状；
- 自旋角动量与轨道角动量；
- 相干性与相关函数；
- 光子数与光子统计；
- 压缩、纠缠和其他非经典量子态结构。

这些并不是彼此独立的“不同种光”，而是同一个场的不同坐标、可观测量或状态性质。所谓“光信息”，本质上也是编码在这些场状态和相关性中的信息，而不是另一种物质本体。

## 2. 物质

“物质”不是只指玻璃、晶体或金属，而是所有能够产生、引导、吸收、散射、放大、探测或响应光的物质自由度。

它包括：

- 电子与空穴；
- 原子、离子、分子；
- 在相关波段起作用的原子核自由度；
- 晶格振动与声子；
- 自旋与磁振子；
- 激子；
- 自由载流子与等离子体振荡；
- 超导或其他集体电子自由度；
- 气体、液体、玻璃、晶体、金属、半导体、生物组织等实际材料。

光学器件本质上也是“结构化物质”。

透镜，是具有特定几何形状和折射响应的物质。  
波导，是支持特定电磁本征模的结构化物质。  
超表面，是在亚波长尺度设计过的电磁响应分布。  
探测器，是被设计成把场态转化为电子、热、化学或机械记录的物质系统。

在宏观经典描述里，大量物质自由度常常可以被压缩成几个响应函数：

\[
\varepsilon(\mathbf r,\omega),\quad
\mu(\mathbf r,\omega),\quad
\sigma(\mathbf r,\omega),\quad
\chi^{(1)},\chi^{(2)},\chi^{(3)},\ldots
\]

而在微观或量子层面，这些响应函数又来自物质本身的 Hamiltonian，以及物质与电磁场之间的耦合。

## 3. 相互作用

真正把“场”和“物质”连接成光学现象的，是相互作用。

| 现象 | 场—物质视角 |
| --- | --- |
| 反射 / 折射 | 边界与材料响应重新组织电磁场 |
| 吸收 | 场的能量转移到物质自由度 |
| 发射 | 激发态物质把能量转移给电磁场 |
| 受激辐射 | 入射场驱动物质产生相干辐射 |
| 散射 | 物质改变场的动量、相位、偏振或频率 |
| 色散 | 物质响应依赖频率 |
| 双折射 | 物质响应依赖方向和偏振 |
| 非线性光学 | 物质响应不再与场幅线性对应 |
| Raman / Brillouin | 光与分子、振动或声学自由度耦合 |
| 磁光效应 | 电磁响应与磁序或自旋耦合 |
| 等离激元 | 电磁场与集体电荷运动耦合 |
| 极化激元 | 光与物质激发强耦合并形成混合本征态 |
| 光力学 | 光场与机械模式交换能量和动量 |
| 光电探测 | 场态在物质中产生可读出的激发 |

干涉和衍射不要求空间中每一点都有材料参与。它们主要属于场本身的叠加与传播动力学。框架仍然成立：干涉、衍射主要落在“场”这一侧；光阑、边界、光源和探测器则属于物质或边界条件。

## 4. 同一个框架覆盖所有理论层次

### 底层场论

对通常的光—物质问题，量子电动力学提供最微观的场论语言：

\[
S = S_{\mathrm{EM}} + S_{\mathrm{matter}} + S_{\mathrm{interaction}}.
\]

底层自由度是电磁规范场和带电物质量子场。

### 有效量子理论

量子光学、腔量子电动力学等，只保留真正相关的少数光学模式与物质模式。典型模型如：

\[
H =
\hbar\omega_c a^\dagger a
+\frac{\hbar\omega_0}{2}\sigma_z
+\hbar g(a^\dagger\sigma_-+a\sigma_+)
+\cdots.
\]

结构仍然非常清楚：

\[
\text{光场模式}+\text{物质模式}+\text{耦合}.
\]

### 经典电磁理论

对大多数宏观光学与光子工程：

\[
\nabla\times\mathbf E=-\partial_t\mathbf B,\qquad
\nabla\times\mathbf H=\mathbf J+\partial_t\mathbf D,
\]

再加本构关系、源和边界条件。

### 波动光学

在适当近似下，Maxwell 理论进一步退化为波动方程、Helmholtz、Fresnel、Fourier、傍轴传播等模型。

### 几何光学

当波长远小于介质与结构变化的尺度时，场可以用 eikonal 或光线表示。光线不是新的基本实体，而是电磁场在短波极限中的有效描述。

因此，可以把整个理论层级看成：

\[
\text{QED}
\rightarrow
\text{有效光—物质 Hamiltonian}
\rightarrow
\text{Maxwell + 材料响应}
\rightarrow
\text{波动光学}
\rightarrow
\text{几何光学}.
\]

越往左越微观、越基础；越往右越简洁，但适用条件更强。

| 领域 / 尺度 | 典型表示 |
| --- | --- |
| 量子光学 | 量子化光场模式 + 量子发射体 + 耦合 |
| 纳米光子学 | Maxwell 场 + 纳米尺度结构化响应 |
| 等离激元 | 电磁场 + 电子密度集体模式 |
| 超表面 | 电磁场 + 亚波长人工 susceptibility |
| 集成光子学 | 导模 + 波导 / 谐振腔物质结构 + 耦合 |
| 光纤光学 | 导模 + 折射率分布 + 色散 / 非线性 |
| 激光物理 | 腔场 + 增益介质 + 泵浦 + 损耗 |
| 成像 | 传播场 + 被测物体响应 + 探测器 + 反演 |
| 光谱 | 制备场 + 样品自由度 + 测得响应 |
| 几何光学 | 光线 / eikonal + 界面和折射率分布 |
| 天文光学 | 场传播 + 物质 + 大气 / 时空背景 |

## 6. 同一个框架覆盖整个电磁谱

从 radio、microwave、THz、infrared、visible、UV、X-ray 到 gamma-ray，本质上仍然是同一个电磁场。真正发生巨大变化的是：在不同频率和能量下，哪一类物质自由度主导相互作用。

例如：

- 微波：转动、磁自旋、电路与集体电子响应；
- THz：声子、低能激发和载流子动力学；
- 红外：分子振动、声子、热辐射；
- 可见 / 近红外：电子跃迁、介电响应、半导体带间跃迁；
- 紫外：高能电子跃迁与电离；
- X 射线：内层电子与高动量散射；
- γ 射线：核过程与相对论粒子过程。

不同学科对“optics”和“photonics”的波段边界使用习惯不同，但“场—物质—相互作用”这一物理框架本身可以覆盖整个电磁谱。

## 7. 光学器件 = 实现特定变换的结构化物质

工程上可以把任何光学器件写成：

\[
\text{输入场态}
\longrightarrow
\text{结构化物质 + 相互作用}
\longrightarrow
\text{输出场态 / 物质态}.
\]

理解一个器件，只需要回答五个问题：

1. 输入的场态是什么？
2. 这里有什么材料和几何结构？
3. 适用什么耦合规律？
4. 输出的场或物质状态是什么？
5. 最终测量什么量？

例如：

- **透镜：**几何形状与折射响应改变波前。
- **偏振片：**各向异性物质选择或转换偏振分量。
- **波片：**双折射物质产生受控相位差。
- **光栅：**周期结构耦合不同动量分量。
- **光纤：**折射率分布支持导模，并控制色散与非线性。
- **激光器：**被泵浦增益介质与谐振场模形成驱动—耗散系统。
- **相机：**电磁能量转化为电子电荷，再转化为数据。
- **SLM：**外部控制改变材料的相位、振幅或偏振响应。
- **超表面：**亚波长结构实现设计好的局域或非局域散射算符。

## 8. 几乎所有光学实验都可以写成状态变换链

一个足够通用的实验链条是：

\[
\text{光源}
\rightarrow
\text{状态制备}
\rightarrow
\text{传播}
\rightarrow
\text{样品 / 器件相互作用}
\rightarrow
\text{探测}
\rightarrow
\text{推断 / 控制}.
\]

它在物理上对应：

- 光源通过物质—场相互作用生成或制备场态；
- 传播阶段让场自身演化；
- 样品和器件改变场态与物质态；
- 探测器再次通过场—物质相互作用产生记录；
- 数据分析把观测量映射为真正关心的科学量；
- 反馈再修改光源、器件或样品控制，形成闭环。

这正是基础理论、实验系统和自动化实验室之间最干净的桥梁。

## 9. 光学工程经常就是逆问题

正问题是：

\[
(\text{场},\text{物质},\text{耦合})
\longrightarrow
\text{可观测量}.
\]

设计问题则反过来：

\[
\text{目标观测量 / 目标变换}
\longrightarrow
\text{材料、几何、控制和场态制备}.
\]

镜头设计、逆向纳米光子学、超表面综合、脉冲整形、照明设计、计算成像、实验自动控制，都可以这样统一理解。

优化变量主要来自三类：

- **场：**振幅、相位、光谱、偏振、空间模式、时间模式；
- **物质：**材料成分、几何、拓扑、温度、载流子密度、磁化状态；
- **相互作用 / 控制：**耦合强度、泵浦、偏压、调制、边界条件、时序。

## 10. 测量与信息也可以放入同一框架

测量不需要再引入第四种“物理本体”。探测器仍然是一个与场耦合的物质系统，只是这种相互作用被设计成能够留下稳定记录。

经典上，我们测量强度、相位、光谱、偏振、到达时间等量。

量子上，测量可以用 observable 或 POVM 表示，它们作用于场—物质状态；实际测量结果仍然来自场与探测装置之间的物理耦合。

信息编码在可区分的场态或场—物质联合态中，例如：

\[
\text{振幅、相位、频率、偏振、空间、时间、光子数、相关性、纠缠}.
\]

通信、传感和成像的差别，主要在于制备什么状态、通过什么信道、以及如何从输出做推断。

## 11. 这个框架的边界

**不是所有光学计算都应该从 QED 开始。**  
应该使用能够保留当前问题关键物理的最低复杂度模型。

**物质不一定是被动的。**  
增益、受驱介质、非线性响应、非平衡载流子、主动量子系统都属于物质动力学。

**场和物质不一定总能干净分开。**  
在强耦合下，极化激元等混合准粒子才是自然本征态。三元分解仍能说明它们来自哪些父自由度以及如何耦合，但真实本征态已经混合。

**几何通常不是第四种物质本体。**  
在实验室光学中，它主要通过材料布局、界面与边界条件体现。只有在引力光学等问题中，时空几何才应作为真正的背景自由度单独加入。

**并非所有电磁现象在学科命名上都叫“光学”。**  
这个框架比传统学科边界更宽。

## 12. 三种最短、最准确的表述

### 科学表述

> 光学与光子学研究电磁场的状态与动力学、物质的状态与响应，以及二者之间产生、变换、引导、探测和控制光的相互作用。

### 工程表述

> 一个光学系统制备一个场，让它传播并与结构化物质相互作用，再把得到的场态或物质态转化为有用功能或可测量结果。

### 底层物理表述

> 光是电磁量子场及其激发；光学现象来自场自身的动力学，以及它与物质的耦合，并受相关背景几何和环境约束。

## 13. 任意光学问题的统一建模检查表

面对任何光学问题，先明确：

1. **场：**经典还是量子？波长、带宽、模式、偏振、相干性、功率 / 光子统计是什么？
2. **物质：**真正起作用的微观或有效自由度是什么？
3. **相互作用：**线性、非线性、共振、耗散、散射、增益还是测量？
4. **几何：**维度、界面、边界、周期性、无序、端口如何定义？
5. **物理区间：**量子 / 经典、近场 / 远场、线性 / 非线性、弱 / 强耦合、平衡 / 驱动？
6. **近似层级：**QED、有效 Hamiltonian、Maxwell、Helmholtz、傍轴、耦合模还是光线？
7. **观测量：**场、光谱、图像、力、温度、电流、计数率、相关函数还是态保真度？
8. **验证：**守恒律、数值收敛、极限情形、标定和实验不确定度是否闭合？

只要这八项说清楚，一个光学问题通常已经足够规范，可以进一步选择理论模型、仿真软件、实验方案或自动化工作流。
